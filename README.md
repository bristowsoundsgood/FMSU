# F MY S___ UP
Heavy audio processor designed for drums. This project is my opportunity to be creative and apply learned knowledge of DSP.

Beyond specific signal processing techniques, these are the current goals for the project:
* Support for any number of channels
* Support for any buffer size, down to 1 sample (i.e., performant / real-time safe code)
* Fancy GUI, written in JUCE (or maybe TypeScript)
